The Ledger

Arrays, objects, and looping through data — the building blocks of the queries, not the answers to any specific one.

Arrays — a list of things

An array holds a list of values in order. You get one item out with square brackets and a position (starting at 0).

const fruits = ["apple", "pear", "plum"];
fruits[0]; // "apple"
fruits.length; // 3

Objects — a bundle of named values

An object holds named properties. You get one out with a dot and the name.

const person = { name: "Sam", age: 34 };
person.name; // "Sam"
person.age;  // 34

An array of objects — like the ledger you're working with — combines both: a list, where each item has named fields.

const orders = [
  { item: "desk", price: 120 },
  { item: "lamp", price: 25 }
];
orders[0].item;  // "desk"
orders[1].price; // 25

Looping through an array

transactions.length tells you how many items there are, so the loop always covers exactly the right number regardless of how big the list is.

for (let i = 0; i < orders.length; i++) {
  console.log(orders[i].item);
}

The accumulator pattern

To build up a total (or a count) across a loop, start a variable before the loop, then add to it inside.

let total = 0;
for (let i = 0; i < orders.length; i++) {
  total += orders[i].price;
}
// total is now 145

total += x

Shorthand for total = total + x. Same idea works for counting: count++ is shorthand for count = count + 1.

Common mistake: declaring let total = 0 inside the loop — it resets to 0 every time round, so you only ever get the last item's value.

Filtering inside a loop

Combine the accumulator with an if to only add matching items.

let total = 0;
for (let i = 0; i < orders.length; i++) {
  if (orders[i].item === "desk") {
    total += orders[i].price;
  }
}
